# 清新浅色报告样式

## 默认生产方式

使用随包 `assets/report-template.html`，只填标题、来源、正文、节点与分支；不重新选设计系统，不默认启用额外交互图工具。模板的示例节点只是组件用法，必须替换成目标的实际层和关系。流程图可用 HTML/CSS 节点，也可复用已验证 SVG；不依赖联网 CDN。

保留主架构、逐层解释、逐项验货和自己的流程在正文中；次要接口、长源码证据放 `details`，完整内容仍在文件里。保留模板对宽表、代码与图形的局部滚动容器，不能靠整体缩小文字解决溢出。

一次事实底稿同时用于 HTML 与 Markdown。优先复用当前可用的转换方式；没有转换工具时按同一底稿填入两个格式，不为本次报告新建通用渲染框架或安装依赖。

## 标准档验收（默认）

1. 一次内容检查：主层及关键分支覆盖、接口准确、证据可追溯、两层齐全；核对正文中实际引用的源码，不以行号存在代替事实判断。检查本地链接、内部锚点和未替换的模板标记。
2. 在同一浏览器空间查看一次桌面渲染：首屏、总图、最复杂分支或最长表格；能在同轮完成就批量读取，不默认每张图都截图。页面确有遮挡再修对应组件。
3. 做一次窄屏宽度检查（例如 390px）：无整页横向溢出，宽表/图在自身容器滚动。无需再检查多个相近桌面尺寸、深色主题或把长文塞进一屏。
4. 只对修改过的部分复检；已通过且未改的内容不再全量截图。记录实际通过、失败和未测项目。

用户明确要求审计档时才追加多尺寸、全部图截图等检查，并先说明新增范围；审计档仍不能执行未授权的目标代码。

## 有界回退

| 触发条件 | 一次修复 | 仍失败时 |
|---|---|---|
| 自定义图重叠/裁切 | 拆为总览与分支、调整问题节点 | 改用模板纵向节点组件，保留所有关键判断与去向 |
| 浏览器或截图超时 | 在同一空间按工具规范恢复一次 | 保存文件，标注视觉检查未完成，不循环尝试多个工具 |
| 页面局部过宽 | 给问题图/表增加局部滚动或换行 | 明确未解决位置，不宣称验收通过；不删正文骗过检查 |

## 样式基线

```css
:root {
  --page: #F7F5EF;
  --card: #FFFFFF;
  --ink: #263238;
  --muted: #60717A;
  --line: #DDE7E3;
  --mint: #4E8C80;
  --sky: #73A8C7;
  --sun: #E6B85C;
  --coral: #D77963;
}
```

- 头图区用很浅的薄荷/天青色块，不用深色渐变。
- 解剖层与化用层各有清晰的编号色标，但卡片底色保持白色。
- 架构图以横向数据流或纵向步骤呈现，箭头清晰，不画无意义装饰。
- 代码证据收进“证据抽屉”或页末，不盖过白话解释。
- 手机宽度时表格横向可滚动，正文不少于 16px。
